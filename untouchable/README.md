# UNTOUCHABLE — Histoire Interactive

Roman interactif en PHP. Style dark romance / thriller.

## Déploiement sur Render (gratuit)

### Étape 1 — GitHub
1. Crée un repo GitHub (public ou privé)
2. Upload les 3 fichiers : `index.php`, `Dockerfile`, `render.yaml`

### Étape 2 — Render
1. Va sur [render.com](https://render.com) → **New** → **Web Service**
2. Connecte ton repo GitHub
3. Render détecte automatiquement le `Dockerfile`
4. Clique **Deploy** — c'est tout !

> ⚠️ Le plan gratuit Render s'endort après 15 min sans visiteur.
> Premier chargement peut prendre ~30 secondes.
